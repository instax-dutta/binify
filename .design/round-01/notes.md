# Round 01 — direction notes

## Category & benchmark
Encrypted one-time pastebin ("burn after read"). The current UI is a Spotify clone:
dark #121212, green #1ed760, feature-card row, rounded pills. It looks borrowed.

Benchmarks in category: PrivateBin (utilitarian form), OneTimeSecret (corporate clean),
tor-style .onion drop services (raw brutal). None own an identity. The category is open:
nobody has made "burning a secret" feel like an event.

## The product's own truths (all real features)
- encryption happens on YOUR machine; server holds noise ("Server only sees noise" — already in the copy!)
- single-read / view-limit: the paste dies when read
- self-destruct timer
- revocation

"Secretive society" fits spycraft, not fantasy: dead drops, case files, burn notices,
cipher rooms. The theme maps to the product mechanics 1:1.

## Three directions, three different engines
01 DEAD DROP — engine: historical media (mid-century classified dossier/case file)
   Skeleton: 画面即界面 — the interface IS a case-file form. Light manila. Stamp red.
02 SANCTUM — engine: material × environment (aged vellum × candlelit archive at night)
   Skeleton: 居中单一物件 — one slip centered in darkness. Warm black, wax, amber.
03 WIRE — engine: deliberate rule-breaking (industrial dispatch / teletype grid)
   Skeleton: 网格拼贴 — dense dispatch grid. Paper white, ink, signal orange.
   Signature: LIVE REDACTION — a black sweep shows "what the server sees" as you type.

## Differentiation check
- Skeletons: form-as-artifact / single centered object / dispatch grid — all different ✓
- Palettes: manila+stamp red (light warm) / night+amber+wax (dark warm) / white+orange (light cold) ✓
- Type: typewriter / high-contrast serif / condensed gothic + mono ✓
- Same tone family (serious — evidence locks it), differ on composition, color identity, signature ✓
- None resembles the Spotify baseline; none resembles each other ✓
- 03 breaks the category default (dark hacker terminal) by being bright paper ✓
